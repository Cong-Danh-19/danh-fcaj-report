#### Objective
In this final deployment step, we will use **Amazon CloudFront**, a global Content Delivery Network (CDN), to distribute our frontend securely. CloudFront caches the React static files at edge locations worldwide for ultra-low latency and provides default **HTTPS** encryption for our application.
