#### Mục tiêu
Trong bước này, chúng ta sẽ tạo hai cổng API Gateway: một HTTP API cho các yêu cầu tĩnh (lấy dữ liệu) và một WebSocket API cho giao tiếp 2 chiều thời gian thực. Các API này đóng vai trò là cửa ngõ để giao diện React kết nối với các hàm Lambda.
