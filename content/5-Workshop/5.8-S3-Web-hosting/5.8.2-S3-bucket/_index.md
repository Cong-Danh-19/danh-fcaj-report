#### 5.8.2. Create the Hosting S3 Bucket
1. Go to the **Amazon S3** console and click **Create bucket**.
![S3 web hosting](/images/5-Workshop/5.8-S3-Web-hosting/Screenshot1.png)
2. **Bucket name**: Enter a globally unique name (e.g., **`chatapp-frontend-2026`**).
![S3 web hosting](/images/5-Workshop/5.8-S3-Web-hosting/Screenshot2.png)

3. **Block Public Access settings**: Uncheck Block all public access and check the warning acknowledgment box.
![S3 web hosting](/images/5-Workshop/5.8-S3-Web-hosting/Screenshot3.png)

4. Click **Create bucket**.
![S3 web hosting](/images/5-Workshop/5.8-S3-Web-hosting/Screenshot4.png)
